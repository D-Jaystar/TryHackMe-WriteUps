# 👋 Cybersecurity Portfolio — Djaystar

Welcome! This is my personal cybersecurity portfolio, where I document TryHackMe rooms, CTFs, and other hands-on security work as I build toward a career in IT/programming after a background in a completely different field.

## 🧭 About this portfolio

I'm transitioning into IT and cybersecurity through self-directed study, and this portfolio is where I log that progress in a structured, readable way. Every writeup here reflects my own hands-on work — the commands I actually ran, the mistakes I made along the way, and how I got from "stuck" to "solved."

## 📂 How the repositories are organized

The writeups are split across **two repositories**, one per language:

| Repository | Language | Purpose |
|---|---|---|
| `dutch` | 🇳🇱 Dutch | Original-language writeups |
| `english` | 🇬🇧 English | English translations of the same writeups, for broader/international readers |

Inside each repository, writeups are grouped into **subfolders by room or challenge category**, for example:

```
english/
├── cracking-authentication/
│   └── checkmate-writeup.md
├── reverse-engineering/
│   └── compiled-writeup.md
└── ...
```

Each subfolder represents a category of room (e.g. cracking/authentication, reverse engineering, web exploitation, etc.), and each writeup follows the same format: goal → step-by-step approach → commands and output → result → a short reflection on what it taught me.

## 📝 A note on how these are written

Each writeup starts as my own raw notes and terminal logs, taken while working through the room. I use AI to help structure and clean up that raw material into a readable writeup — the technical content, commands, and results are all mine, the AI just helps with formatting and clarity.

My original, unedited notes (screenshots, half-finished thoughts, false starts included) live in my personal Obsidian vault. If you'd like to see the raw version of any writeup here, just reach out.
